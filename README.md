# 生命论（明本论）

> 从「在感」这个唯一无需怀疑的起点出发，推导出人的解放何以可能。
>
> ——北原慢热

一套以**操作**而非实体为第一性的哲学：感先于操作，操作先于实体；活的存在就是自指操作；知道怎么反自指，才知道怎么正自指。它同时给出了这门哲学的数学形式化（操作范畴论 / PTC 公理系统）。

## 核心逻辑（三句话）

1. **感先于操作，操作先于实体。** 你此刻在读这些字、你感到了——这是最直接的事实，比「我思」「物质」都直接。感展开为操作，操作沉淀为实体。不是先有一个「东西」然后它「作用」，是作用本身才是最基本的事实。
2. **自指操作即生命。** 系统以自身为输入、输出又返回自身以维持自身——呼吸维持身体，身体维持呼吸；劳动维持社会，社会维持劳动。这就是 S=f(S)。生命不可被彻底资本化。
3. **知道怎么反自指，才知道怎么正自指。** 反自指是自指的丧失：结构的规定性逐一坍塌，寄生结构消耗宿主。资本、癌细胞、官僚制、经文化，都是反自指。解放就是恢复自指——操作权回归劳动者。

## 阅读提示

- 这不是书斋里的哲学，它自觉地站在劳动者一边，并把这一立场本身交给同样的审查（生命论自身亦不免于审查）。
- 全书一边清算旧哲学（从黑格尔、费尔巴哈到马克思，从尼采、海德格尔到中国传统思想），一边在操作的地基上重建；引用处尽量给出原典篇章节，欢迎据原典核验。
- 数学形式化（卷十一、附录七）是同一门哲学的「器」层，不熟悉线性逻辑与范畴论的读者可先读卷一至卷七。
